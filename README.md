# QCL Labs

A collection of executed Quantum Computing Lab notebooks built with Qiskit.

## Notebooks

- [Quantum Circuit Basics](notebooks/01_quantum_circuit_basics.ipynb)
- [Quantum Gates and Statevectors](notebooks/02_quantum_gates_and_statevectors.ipynb)
- [Quantum Full Adder](notebooks/03_quantum_full_adder.ipynb)
- [Deutsch's Algorithm](notebooks/04_deutsch_algorithm.ipynb)
- [Deutsch-Jozsa Algorithm](notebooks/05_deutsch_jozsa_algorithm.ipynb)
- [Bernstein-Vazirani Algorithm](notebooks/06_bernstein_vazirani_algorithm.ipynb)

## Run locally

Use Python 3.12 or 3.13 and install the required packages:

```sh
python -m pip install jupyter matplotlib pylatexenc qiskit qiskit-aer
jupyter lab
```

Open a notebook and run its cells from top to bottom. The committed notebooks also include saved outputs.
